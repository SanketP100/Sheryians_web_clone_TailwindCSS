# Shreyansh_Coding_School_Landing_Page_Clone

This project is a responsive clone of the Shreyansh Coding School landing page, developed using HTML and Tailwind CSS. The design is fully responsive, leveraging Tailwind CSS breakpoints to ensure optimal viewing across various devices.

**Features**

Responsive Design: Tailwind CSS breakpoints are used to adapt the layout for different screen sizes.

Clean Code: Structured with semantic HTML for readability and maintainability.

Efficient Styling: Tailwind CSS utilities ensure quick styling without sacrificing performance.
